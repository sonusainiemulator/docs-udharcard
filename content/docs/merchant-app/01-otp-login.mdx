UdharCard Merchant App में दुकानदारों के लिए पासवर्ड-मुक्त (Passwordless) सुरक्षित प्रमाणीकरण उपलब्ध है।

## 📋 आवश्यकताएँ (Prerequisites)
- एंड्रॉइड फोन (Android 8.0 या उच्चतर)
- सक्रिय सिम कार्ड (SMS OTP प्राप्त करने के लिए)
- इंटरनेट कनेक्टिविटी (4G / 5G / Wi-Fi)

---

## 🚀 चरणबद्ध लॉगिन प्रक्रिया (Step-by-Step Flow)

### 1. ऐप लॉन्च करें
- ऐप खोलने पर आपको स्प्लैश स्क्रीन (Splash Screen) दिखाई देगी।
- यदि आप पहले से लॉग इन हैं, तो ऐप अपने आप सुरक्षित टोकन रीफ्रेश करके सीधे डैशबोर्ड पर ले जाएगा।

### 2. मर्चेंट मोबाइल नंबर दर्ज करें
- 🇮🇳 भारतीय तिरंगे झंडे के साथ प्रदर्शित `+91` कोड के बाद अपना 10-अंकों का वैध मोबाइल नंबर दर्ज करें।
- **Get OTP / ओटीपी प्राप्त करें** बटन दबाएँ।

### 3. Firebase 6-अंकों का OTP सत्यापित करें
- आपके मोबाइल पर तुरंत 6 अंकों का SMS कोड आएगा।
- कोड स्क्रीन पर डालें; यह स्वचालित रूप से सत्यापित हो जाएगा।

### 4. बैकएंड Sanctum टोकन सिंक
- ऐप बैकएंड API `/api/merchant/otp-login` को कॉल करता है।
- यदि आप नए मर्चेंट हैं, तो आपका अकाउंट तुरंत सुरक्षित रूप से बन जाता है और 1-वर्षीय Sanctum Bearer टोकन जारी होता है।

<Callout type="tip" title="Automatic Token Refresh">
  यदि कभी इंटरनेट टूटने से 401 Unauthorized त्रुटि आती है, तो ऐप की बैकग्राउंड री-ट्राई प्रणाली बिना किसी असुविधा के टोकन अपने आप रीफ्रेश कर देती है।
</Callout>
